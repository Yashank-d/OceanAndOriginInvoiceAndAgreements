# Booking Schedule Specification

This is a separate document from the Master Client Booking Agreement.

## Sections

### CLIENT
- Client name
- Phone
- Email
- Address

### BOOKING
- Booking ID
- Event/shoot
- Event date
- Location
- Coverage timing

### SERVICES
- Package/service
- Coverage
- Deliverables

### DELIVERABLES
- Photography
- Films
- Albums
- Prints
- Other agreed deliverables

### FEES
- Total fee
- 50% booking advance
- 30% pre-event
- 20% final
- Payment dates
- Invoice reference

### TRAVEL & ACCOMMODATION
- Included/not included
- Details

### DELIVERY
- Expected timeline
- Revision limits
- Archival period

### SPECIAL TERMS
- Free text

### CONFIRMATION
- Client signature
- Service provider signature
- Date

## Output
Normally 1 to 2 pages.
Use the same Parva document system.
Keep it clean and practical.
