## Visual direction
The documents must feel like the previously approved Parva agreement style.

Use:
- Warm ivory / off-white
- Deep burgundy / wine accents
- Elegant serif display typography
- Clean readable sans-serif body/interface typography
- Generous whitespace
- Thin subtle rules
- Small Parva logo
- Strong hierarchy
- Restrained editorial character
- Professional legal-document spacing

Avoid:
- Generic SaaS templates
- Government-form appearance
- Colourful startup styling
- Canva-style decoration
- Gradients
- Huge graphics
- Excessive cards
- Over-decoration

The result must feel premium and editorial while remaining unmistakably a real professional document.

## Logo
Use the existing Parva logo asset in the repository if available.
Never recreate or alter the logo.

## Print quality
Documents must remain readable when printed.
Text must remain selectable in PDFs.
Never use screenshots of HTML as the PDF.
