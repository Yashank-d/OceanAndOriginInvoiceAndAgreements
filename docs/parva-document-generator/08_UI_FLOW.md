## Agreement flow

New Agreement
→ Client
→ Booking
→ Services & Deliverables
→ Commercial
→ Delivery
→ Special Terms
→ Review
→ Save Draft / Generate PDF / Generate DOCX

## Invoice flow

New Invoice
→ Client
→ Invoice details
→ Line items
→ Additional charges
→ Tax/discount
→ Payment
→ Review
→ Generate

## Booking Schedule flow

New Booking Schedule
→ Shared booking information
→ Review
→ Generate

## Review
Preview should resemble the final generated document.

Actions:
- Edit
- Save Draft
- Generate PDF
- Generate DOCX

Do not make users repeatedly re-enter shared information.

## UX principles
- Fast
- Minimal
- Obvious
- Spacious
- Low cognitive load
- No unnecessary confirmation steps
- Preserve entered data
- Clear validation messages
